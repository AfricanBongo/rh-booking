# RoyalHouse Booking - 3-Day MVP Implementation Plan (v2)

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Use sub-agent driven development. Pause after each page/flow completion for developer visual feedback.

**Goal:** Build a conference room booking platform MVP with marketing site, passwordless auth, room booking, roommate matching, payments, merch, and children registration in 3 days.

**Architecture:** Next.js 16 on Cloudflare as thin client. Supabase for auth (magic link), transactional data, and Edge Functions. Strapi on Coolify as headless CMS for content. Stripe Checkout for payments with stripe-sync-engine mirroring to Supabase. Data access layer in `lib/data/` abstracts the source.

**Tech Stack:** Next.js 16, React 19, Tailwind CSS 4, HeroUI v3, Supabase (Auth + DB + Edge Functions), Strapi v5 (headless CMS), Stripe Checkout, stripe-sync-engine, Vitest, Cloudflare Pages

## Database Schema (Supabase)

> This schema is informed by the screen mapping. May be adjusted during implementation if needed.

### Tables

```sql
-- Church Branches (seeded, admin-editable future)
CREATE TABLE church_branches (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  name TEXT NOT NULL UNIQUE,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- Profiles (extends auth.users)
CREATE TABLE profiles (
  id UUID PRIMARY KEY REFERENCES auth.users(id) ON DELETE CASCADE,
  full_name TEXT NOT NULL,
  phone TEXT NOT NULL,
  gender TEXT NOT NULL CHECK (gender IN ('male', 'female')),
  age INTEGER NOT NULL CHECK (age > 0),
  church_branch_id UUID NOT NULL REFERENCES church_branches(id),
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- Conference Registrations (user registered for conference, no room yet)
CREATE TABLE conference_registrations (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID NOT NULL REFERENCES profiles(id) ON DELETE CASCADE,
  conference_id TEXT NOT NULL, -- Strapi ID
  check_in TIMESTAMPTZ NOT NULL,
  check_out TIMESTAMPTZ NOT NULL,
  created_at TIMESTAMPTZ DEFAULT NOW(),
  UNIQUE(user_id, conference_id)
);

-- Room Groups (a shared room instance)
CREATE TABLE room_groups (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  conference_id TEXT NOT NULL,
  room_type_id TEXT NOT NULL, -- Strapi ID
  bed_preference TEXT NOT NULL CHECK (bed_preference IN ('king', 'double')),
  relationship_type TEXT CHECK (relationship_type IN ('married', 'siblings', 'none')),
  max_occupants INTEGER NOT NULL CHECK (max_occupants IN (1, 2, 4)),
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- Bookings (one per person per room group)
CREATE TABLE bookings (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID NOT NULL REFERENCES profiles(id) ON DELETE CASCADE,
  room_group_id UUID NOT NULL REFERENCES room_groups(id) ON DELETE CASCADE,
  conference_id TEXT NOT NULL,
  total_price INTEGER NOT NULL, -- cents, individual share
  amount_paid INTEGER DEFAULT 0, -- cents
  status TEXT NOT NULL DEFAULT 'confirmed' CHECK (status IN ('confirmed', 'cancelled')),
  created_at TIMESTAMPTZ DEFAULT NOW(),
  UNIQUE(user_id, conference_id)
);

-- Invitations
CREATE TABLE invitations (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  room_group_id UUID NOT NULL REFERENCES room_groups(id) ON DELETE CASCADE,
  inviter_id UUID NOT NULL REFERENCES profiles(id),
  invitee_id UUID NOT NULL REFERENCES profiles(id),
  status TEXT NOT NULL DEFAULT 'pending' CHECK (status IN ('pending', 'accepted', 'declined', 'expired')),
  created_at TIMESTAMPTZ DEFAULT NOW(),
  expires_at TIMESTAMPTZ
);

-- Children
CREATE TABLE children (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  parent_id UUID NOT NULL REFERENCES profiles(id) ON DELETE CASCADE,
  booking_id UUID NOT NULL REFERENCES bookings(id) ON DELETE CASCADE,
  age INTEGER NOT NULL CHECK (age > 0),
  gender TEXT NOT NULL CHECK (gender IN ('male', 'female')),
  is_billable BOOLEAN GENERATED ALWAYS AS (age >= 12) STORED
);

-- Merch Orders
CREATE TABLE merch_orders (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID NOT NULL REFERENCES profiles(id) ON DELETE CASCADE,
  merch_item_id TEXT NOT NULL, -- Strapi ID
  pickup_location_id TEXT NOT NULL, -- Strapi ID
  stripe_payment_id TEXT,
  status TEXT NOT NULL DEFAULT 'pending' CHECK (status IN ('paid', 'pending')),
  created_at TIMESTAMPTZ DEFAULT NOW()
);
```

### Key Schema Changes from v1
- `church_branches` table replaces hardcoded constant (ComboBox fetches from Supabase)
- `conference_registrations` is separate from `bookings` (user can register without booking a room)
- `room_groups` holds shared room state (type, bed preference, relationship, max occupants)
- `bookings` references `room_group_id` (not directly a room type)
- No password-related fields (magic link auth)
