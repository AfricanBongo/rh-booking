# RoyalHouse Booking - 3-Day MVP Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Build a conference room booking platform MVP with marketing site, auth, room booking, roommate matching, payments, merch, and children registration in 3 days.

**Architecture:** Next.js 16 on Cloudflare as thin client. Supabase for auth, transactional data, and Edge Functions. Strapi on Coolify as headless CMS for content (conferences, rooms, merch). Stripe Checkout for payments with stripe-sync-engine mirroring to Supabase. Data access layer in `lib/data/` abstracts the source from components.

**Tech Stack:** Next.js 16, React 19, Tailwind CSS 4, HeroUI, Supabase (Auth + DB + Edge Functions), Strapi (headless CMS), Stripe Checkout, stripe-sync-engine, Cloudflare Pages

**Acceptance Criteria:**
